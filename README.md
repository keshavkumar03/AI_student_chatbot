# Student Mental Health Counselor LLM App  

## Overview  

This project is a web application designed to provide personalized mental health guidance to students. It leverages the Gemini Pro large language model (LLM) to analyze student-provided descriptions of their problems and generate tailored recommendations for improvement. The application is built with a React frontend, a Flask backend, and utilizes the Gemini Pro model for its core functionality.  

## Features  

*   **Problem Analysis:**  Analyzes student-provided descriptions of their mental health concerns.  
*   **Personalized Tips:** Provides tailored tips and guidance for improvement based on the analysis.  
*   **Evidence-Based Recommendations:** Employs knowledge of evidence-based practices and therapeutic techniques.  
*   **JSON Output:** The application outputs information in structured JSON format, containing a summary of the problem, thoughts on if it is normal, the potential solutions, the cause of the problem and how it can be improved.  

## Architecture  

The application follows a three-tier architecture:  

1.  **Frontend (React):**  Handles user interaction, input collection, and display of results.  
2.  **Backend (Flask):**  Acts as an API layer, receiving requests from the frontend, interacting with the Gemini Pro model, and returning the model's response.  
3.  **LLM (Gemini Pro):**  The core intelligence of the application, responsible for analyzing the input text and generating personalized advice.

## Setup and Installation  

### Prerequisites  

*   Python 3.7+  
*   Node.js and npm (Node Package Manager)  
*   A Google Cloud project with the Gemini Pro API enabled.  You'll need an API key.  

### Backend Setup (Flask)  

1.  **Clone the repository:**  

    ```bash  
    git clone <your_repository_url>  
    cd your_repository/backend  #Navigate to the backend directory  
    ```  

2.  **Create a virtual environment (recommended):**  

    ```bash  
    python -m venv venv  
    source venv/bin/activate   # On Linux/macOS  
    venv\Scripts\activate  # On Windows  
    ```  

3.  **Install dependencies:**  

    ```bash  
    pip install -r requirements.txt  
    ```  

4.  **Set the Gemini Pro API key:**  

    *   You can set it as an environment variable:  

        ```bash  
        export GOOGLE_API_KEY="YOUR_GEMINI_PRO_API_KEY"  # Linux/macOS  
        set GOOGLE_API_KEY="YOUR_GEMINI_PRO_API_KEY"  # Windows  
        ```  

    *   Or, you can directly add it in your python script (less secure):  

        ```python  
        # In your Flask app (e.g., app.py)  
        import os  
        os.environ["GOOGLE_API_KEY"] = "YOUR_GEMINI_PRO_API_KEY"  
        ```  

5.  **Run the Flask application:**  

    ```bash  
    python app.py  # Or whatever your main Flask file is named  
    ```  

### Frontend Setup (React)  

1.  **Navigate to the frontend directory:**  

    ```bash  
    cd ../frontend  
    ```  

2.  **Install dependencies:**  

    ```bash  
    npm install  
    ```  

3.  **Configure the API endpoint:**  

    *   In your React app, you'll need to configure the API endpoint to point to your Flask backend.  This is usually done in a configuration file or environment variable.  For example, in `.env` or `config.js`:  

        ```javascript  
        // .env.development  
        REACT_APP_API_URL=http://localhost:5000  # Or your Flask backend address  
        ```  

4.  **Start the React development server:**  

    ```bash  
    npm start  
    ```  

## Usage  

1.  Access the application in your web browser (usually at `http://localhost:3000` for the React development server).  
2.  Enter a description of your mental health concern in the provided text area.  
3.  Submit the form.  
4.  The application will display the analysis and personalized recommendations generated by the Gemini Pro model in a structured JSON format.
